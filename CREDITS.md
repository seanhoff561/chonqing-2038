# Credits

Chongqing 2038 is made entirely in code: geometry, canvas textures and Web Audio synthesis. No third-party art, audio or fonts ship with the game; signs use the player's system CJK fonts.

## Libraries
- three.js (MIT) - rendering
- Vite (MIT), TypeScript (Apache-2.0), Vitest (MIT), Puppeteer (Apache-2.0) - build and test tools, not shipped
